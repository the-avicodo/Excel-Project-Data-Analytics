# Job Market Analysis Project  
## Introduction  
The Job Market Analysis project provides job seekers with useful insights about the data science job market. 

## Skills Used 
- Power Query for ETL
- Power Pivot (measures)
- Pivot tables
- Charts  

## Analysis  
Questions:
1. What are the most in-demand skills in data science job descriptions?
2. What are the most lucrative skills in data science?
3. How do median salaries compare based on country?
4. What is the relationship between the number of skills required and median salary?
## Data Jobs Dataset  
The dataset is a collection of data science job postings from 2023 collected by Luke Barousse. It includes data such as:
- Job title
- Salary
- Skills required
- Job country
