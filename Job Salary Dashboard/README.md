## Intro
This dashboard is useful for job seekers curious about salaries for data science positions.  

## Skills Used
- Data Validation
- Formulas and Functions
- Charts

## Data Jobs Dataset
The data jobs dataset is a detailed collection of data science job postings by Luke Barousse. Useful columns used in this project include:
- job_title_short
- salary_year_avg
- job_country
- job_type (full-time, part-time, etc.)
